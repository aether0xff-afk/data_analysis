2026 데이터과학 최종 결과보고서 개요
AI가 틀렸을 때, 왜 인간은 그 조언을 따라가는가?
— 개인별 행동 이력을 활용한 잘못된 조언 수용 예측

핵심 이야기
정적인 개인 특성만으로 조언과 같은 오답을 예측하려 했으나 예측력이 낮았다. 개인의 다른 판단 10건을 이용해 MLP의 확률을 보정했을 때 같은 평가 자료에서 구별 성능이 높아졌다. 이는 개인별 실제 행동 이력이 유용한 예측 정보임을 보여준다. 다만 의존의 심리적 원인까지 입증하지는 않는다.

1. 문제 정의와 프로젝트 목표
1.1 문제: AI 또는 인간이 틀린 조언을 제시했을 때, 사람이 그 조언과 같은 답을 고르는지 예측한다.
1.2 필요성: AI 기반 의사결정 지원 서비스를 설계할 때 실제 행동의 개인차를 이해할 필요가 있다.
1.3 성공 판단: LR·MLP·개인화 모델을 비교하고, 개인화를 제외한 동일 평가 시행에서 AUC·Accuracy·F1·BCE 개선을 확인한다.
1.4 활용: 조언형 AI 서비스의 개인화 연구. 실제 사용자 판정에 즉시 적용하지 않는다.
1.5 계획 대비 변경: 연구 질문 유지, 273명으로 축소했던 데이터를 원본 조건 검증으로 295명 복원, 정적 모델의 한계를 분석한 뒤 개인별 적응형 보정 추가.

2. 최종 데이터셋의 이해
2.1 Pearson 등(2026)의 얼굴 진위 판단 연구 데이터. 295명 × 80회 = 23,600회 판단.
2.2 틀린 조언 시행 11,800건만 분석. 조언과 같은 오답 5,571건(47.21%), 다른 답 6,229건(52.79%).
2.3 목표 변수 wrong_advice_followed = 1 - response_correct (틀린 조언 시행에 한함).
2.4 입력: 나이, AI 긍정·부정 태도, 인간 신뢰도, 조언 출처, 얼굴 유형(원-핫 인코딩 뒤 8개 특성).
2.5 주의: 같은 오답을 선택했다고 조언 때문에 틀렸다는 인과관계가 성립하지 않는다.

3. 데이터 전처리와 탐색
3.1 #N/A 문자열을 결측값으로 인식, 모델에 쓰지 않는 파생변수의 결측 2건 확인.
3.2 A/B형 배치표와 원본 조건 대조; 제외했던 22명을 복구.
3.3 melt()로 23,600개 판단을 Long 형태로 펼침. pivot_table()으로 판단값 역검증, 불일치 0건.
3.4 분석 데이터 11,800건 생성. 590개 고유 입력 패턴 중 569개에서 목표 0·1이 모두 나와 정적 입력의 한계를 확인.
3.5 참가자 단위 Train 205명(8,200건), Validation 45명(1,800건), Test 45명(1,800건). 표준화는 Train 통계만 사용.

4. 모델 선택과 구현
4.1 PyTorch LR(8→1), MLP(8→4→1 + ReLU), BCEWithLogitsLoss.
4.2 최종 LR: 학습률 0.03, L2 0.1, 4 epoch. MLP: 학습률 0.01, L2 0.01, 7 epoch. Validation 조기 종료.
4.3 기존 모델은 개인별 이전 선택 경향을 직접 보지 못하는 문제가 있다.
4.4 적응형 모델: 기존 MLP 로짓에 개인별 보정값 b_i를 더하고 sigmoid로 확률 계산. 참가자별 첫 10건의 판단으로 b_i를 추정, 나머지 30건을 예측. 보정값 고정 방식과 매 판단 후 갱신 방식을 비교.
4.5 L2 보정 강도는 Validation BCE로 선택(λ=2). 현재 예측하는 시행의 정답은 미리 보지 않는다.

5. 모델 성능 평가와 비교 개선
5.1 기존 Test 1,800건:
LR 정확도 52.89%, F1 0.4436, AUC 0.5348.
MLP 정확도 54.56%, F1 0.5748, AUC 0.5777.

그림 2. LR·MLP AUC 비교 (1,800건)
5.2 동일한 평가 대상 1,350건(45명 × 30건)에서:
고정 MLP 정확도 53.78%, AUC 0.5679.
첫 10건 개인화 후 고정 정확도 66.96%, AUC 0.7119.
매 판단 후 갱신 정확도 67.48%, AUC 0.7211.

그림 3. 적응형 모델 AUC 비교 (1,350건)
5.3 해석: 개인 이력에서 유용한 정보가 나타났고, 지속적 갱신의 추가 효과는 상대적으로 작았다.
5.4 유의: 1,800건의 기존 AUC와 1,350건의 적응형 AUC를 직접 빼서 개선량이라 하지 않는다.

6. 결론 및 고찰(프로젝트 성찰)
6.1 정적 신뢰도·특성만으로는 잘못된 조언과 같은 답을 충분히 구별하지 못했다.
6.2 개인의 과거 판단을 반영하면 같은 평가 집합에서 성능이 개선됐다. 따라서 실제 행동 이력을 중요한 예측 정보로 고려할 필요가 있다.
6.3 미확인 사항: 이전 경험이 판단을 변화시켰는가, AI 의존의 심리적 원인은 무엇인가.
6.4 한계: 목표 변수의 인과 해석 불가; 실제 시행 순서 미확인으로 사후 시뮬레이션; Test 재사용; B형 정오 배치 일부 복원.
6.5 성찰: 모델 크기만 바꾸기보다 입력의 정보량, 실험 조건, 데이터 누수를 먼저 확인하는 것이 중요했다.
