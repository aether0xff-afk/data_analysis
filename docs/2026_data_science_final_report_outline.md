# 2026 데이터과학 최종 결과보고서 — 확정 개요 및 근거 정리

> **연구 제목:** AI가 틀렸을 때, 왜 인간은 그 조언을 따라가는가?  
> **부제:** 개인별 행동 이력을 활용한 잘못된 조언 수용 예측  
> **작성 기준:** 2026-11-04 / 탐구일지, 전처리·LR·MLP 노트북, 적응형 예측 최종 실험 결과  
> **문서 목적:** 수행평가 6개 필수 항목에 맞춘 보고서 작성 기준. 새 실험을 무한히 추가하지 않고, 적응형 모델 분석에서 연구를 마무리한다.

## 연구의 중심 논리

**문제 제기 → 데이터 정제 → 정적 예측의 한계 확인 → 원인 진단 → 개인별 적응형 예측 → 인간의 판단에 대한 제한적인 해석**

- **관찰:** 잘못된 조언이 제시된 11,800회 중 5,571회(47.21%)에서 참가자가 잘못된 조언과 같은 답을 선택했다.
- **기본 모델:** 로지스틱 회귀(LR)와 다층 퍼셉트론(MLP)은 예측력이 낮았다(최종 원래 Test의 MLP ROC-AUC 0.5777).
- **심화:** 동일 참가자의 다른 시행 10건을 개인화에 이용하면, 관찰하지 않은 30건에 대한 구별 능력이 향상됐다(동일 1,350건에서 정적 MLP AUC 0.5679 → 적응형 MLP 0.7211).
- **해석:** 일반적인 신뢰도 설문만으로는 설명되지 않는 개인별 행동 특성을 고려할 필요가 있다.
- **경계:** 이 결과가 ‘잘못된 조언 **때문에** 틀린 이유’를 규명하거나 실시간 미래 예측을 입증하는 것은 아니다.

## 1. 문제 정의와 프로젝트 목표

### 1.1 분석 대상과 해결하려는 문제
- AI 또는 인간이 **틀린 조언**을 했을 때, 사람이 그 조언과 같은 답을 선택하는 현상을 분석한다.
- ‘AI를 신뢰한다고 응답하는 정도’ 등의 정적 특성만으로 실제 판단을 충분히 예측할 수 있는지 확인한다.
- 개인별 실제 판단 이력이 추가될 때 예측이 어떻게 달라지는지 분석한다.

### 1.2 필요성·성공 판단 기준·활용 주체
- 판단 오류를 줄이는 AI 의사결정 지원 시스템 설계에는 누가 조언에 취약할 가능성이 있는지에 관한 정보가 필요하다.
- **성공 판단:** 무조건 다수 클래스를 예측하는 기준 모델과 LR·MLP를 공정하게 비교하고, 개인화 전후를 **동일 평가 집합**에서 Accuracy·F1·ROC-AUC·BCE로 비교한다. 사전에 특정 AUC 수치를 달성 목표로 정했다고 주장하지 않는다.
- **활용 가능 주체:** AI 조언형 서비스 연구자·설계자. 개인화의 유용성을 탐색하는 근거로 활용하되, 현재 모델을 실제 사용자 위험 판정에 바로 적용하지 않는다.

### 1.3 문제정의서 대비 변경 — ‘목표’와 ‘데이터·방법’을 구분
- **핵심 목표 유지:** 잘못된 조언과 같은 답을 선택하는 행동의 예측·분석.
- **데이터 수정:** 초기에 A/B 배치를 확인하지 못해 22명을 제외(273명)했으나 원본 설문과 대조해 295명을 복구했다.
- **방법 확장:** 정적 LR·MLP의 낮은 AUC 원인을 추적한 뒤 개인별 이력 기반 적응형 모델을 추가했다.
- **변경 이유:** 모형의 층을 늘리는 것보다 입력에서 빠진 개인별 행동 정보가 더 중요할 수 있다는 진단을 검증하기 위해서다.

## 2. 최종 데이터셋의 이해

### 2.1 출처·실험 구조
- Pearson 외(2026)의 AI/인간 조언이 포함된 얼굴 판별 공개 연구 자료 및 OSF 데이터.
- 분석용 Excel **295명 × 141열**, 참가자당 **80개 판단**, 총 **23,600건**.
- 조건별 인원: HumanA 74명, HumanB 80명, AI_A 70명, AI_B 71명.
- 조언의 정오 배치는 A/B형에 따라 달라 원본 조건과 대조했다. 특히 B형 정오 배치 일부는 참가자별 집계 결과로 **복원**했으며 원래 제시 화면을 직접 모두 확인한 것은 아니다.

### 2.2 분석 단위와 목표 변수
- 전체 23,600건 중 **잘못된 조언이 제시된 11,800건**만 분석한다(참가자당 40건).
- ‘틀린 조언을 수용’ 지표 `wrong_advice_followed`는 **틀린 조언이 나온 시행에 한해** `1 - response_correct`로 정의한다.
- 1(일치) **5,571건(47.21%)**, 0(불일치) **6,229건(52.79%)**.
- 이진 선택 실험에서 **틀린 조언과 같은 오답을 선택했다**는 관찰 지표이며, 조언이 오답의 **원인**이라는 의미는 아니다.

### 2.3 입력 특성
- 연속형: 나이, AI 긍정 태도, AI 부정 태도, 인간 신뢰도(`human_trust_mean`).
- 범주형: 조언 출처(AI/Human), 얼굴 유형(Real/Synthetic).
- 원-핫 인코딩 뒤 **총 8개 입력 특성**. 참가자 ID는 모델의 일반 입력으로 넣지 않고 분할 및 개인 이력 연결에 사용한다.
- 시행별 얼굴 ID·난이도, 제시 시각과 같은 일부 설명 정보는 현재 정적 모델 입력에 없다.

## 3. 데이터 전처리와 탐색

### 3.1 데이터 정제·전환
1. Excel의 문자 `#N/A`를 결측으로 인식하도록 수정. 파생 통계 변수 `aprime`, `bppd`에서 각 1건(총 2건)의 결측을 확인했으며 모델 핵심 입력은 결측이 없었다.
2. 원본 설문과 조건을 대조해 참가자 22명을 복구, 최종 **295명** 사용.
3. `melt()`로 80개 판단 열을 Long 형태의 **23,600행**으로 전환.
4. `pivot_table()` 역검증에서 판단값 차이 **0건** 확인.
5. A/B별 조언 정오 정보 결합 → 틀린 조언만 필터 → 목표 변수 생성.

### 3.2 탐색 결과
- 잘못된 조언과 같은 답을 선택한 비율 **47.21%**.
- 개인별 수용률은 하위 25% 지점 **35.0%**, 중앙값 **45.0%**, 상위 25% 지점 **57.5%**로 차이를 보였다.
- 입력이 동일한 패턴은 **590종**이며, 그중 **569종**에서 정답 0과 1이 모두 발생했다. 이는 현재 입력만으로 각 시행을 확정적으로 구별할 수 없다는 증거이지만 최대 달성 가능 정확도를 뜻하지는 않는다.
- 나이·신뢰도와 개인별 수용률의 단순 상관관계만으로 인과적 설명을 하지 않는다.

### 3.3 누수 방지·데이터 분할
- 참가자 기준 **Train 205명(8,200건) / Validation 45명(1,800건) / Test 45명(1,800건)**.
- 한 사람의 시행이 학습과 평가 양쪽에 동시에 들어가지 않도록 분리.
- 연속형 표준화는 Train 평균·표준편차만 사용.
- GuidanceUse, 전체 정확도 등 판단 뒤 산출되는 변수는 입력에서 제외.

## 4. 모델 선택과 구현

### 4.1 비교 모델
| 모델 | 구조 | 최종 설정 | 구현·선택 방법 |
|---|---|---|---|
| 기준 모델 | 다수 클래스(0) 일괄 예측 | 학습 없음 | 정확도 착시 점검 |
| 로지스틱 회귀(LR) | 8 → 1 | 학습률 0.03, L2 0.1, 4 epoch | PyTorch 선형층, BCEWithLogitsLoss |
| 다층 퍼셉트론(MLP) | 8 → 4 → 1 | 학습률 0.01, L2 0.01, 7 epoch | PyTorch ReLU 은닉층, BCEWithLogitsLoss |

- Train 참가자에 대한 **4-fold 교차검증** 후 Validation으로 설정 선택.
- LR **10개**, MLP **30개** 등 총 **40개** 설정을 비교.
- 초기 학습에서는 Train 손실 감소와 Validation 손실 악화가 함께 나타나 조기 종료·L2 정규화·모델 크기 축소를 검토했다.
- 이전 단계에서 Test를 반복 확인했다는 사실은 평가 한계로 기록한다.

### 4.2 왜 적응형 모델을 도입했는가
- 일반적 신뢰도나 나이처럼 **고정된 입력**만으로는 개인의 시행별 판단 차이를 잘 구별하지 못했다.
- 따라서 동일 참가자의 다른 시행 결과를 바탕으로 그 사람의 ‘틀린 조언과 같은 답을 고르는 성향’을 추정했다.
- 복잡한 네트워크 확장보다 **개인별 새 정보의 추가 효과**를 검증하는 설계다.

### 4.3 개인별 적응형 모델
- 기존 MLP가 출력한 로짓 `z_MLP`에 참가자별 보정 절편 `b_i`를 더한다.
- **예측식:** `p_i = sigmoid(z_MLP + b_i)`
- 참가자별 **첫 10건을 개인화(보정용)** 에 사용하고 **남은 30건**에서 평가.
- 보정 절편은 과거 관찰 라벨의 정규화된 이항 로그우도를 이용해 추정·갱신. L2 보정 강도 **λ=2**를 Validation BCE로 선택.
- 대조 실험: **10건 보정 후 고정**, **매 평가 결과가 공개될 때마다 갱신**, 개인별 단순 베타-베르누이 추정.
- **실제 시간 순서가 확보되지 않았으므로** ‘첫 10건’은 복원된 열 순서를 따른 가상 공개 순서로, 미래 행동의 온라인 예측이 아닌 **사후 시뮬레이션**이다.

## 5. 모델 성능 평가와 비교 개선

### 5.1 기존 모델 전체 Test 결과 — 1,800건
| 모델 | 정확도 | F1 | ROC-AUC |
|---|---:|---:|---:|
| 다수 클래스 기준 | 52.00% | 0.0000 | 정의 방식에 따라 0.5000 |
| LR | 52.89% | 0.4436 | 0.5348 |
| MLP | 54.56% | 0.5748 | 0.5777 |

- MLP가 수치상 앞서도 AUC 0.5777은 무작위 순위 구별(0.5)에 가까워 실용적 개별 판단 예측력이 약하다.
- LR과 MLP의 차이가 안정적이라고 단정하지 않는다.

### 5.2 적응형 도입 후 공통 Test 결과 — 1,350건
> **중요:** 각 참가자의 10건을 개인화에 사용한 뒤 **나머지 30건 × 45명 = 1,350건**만 비교한다. 위 1,800건 성능과 아래 성능을 직접 비교하지 않는다.

| 모델 | 정확도 | F1 | ROC-AUC | BCE |
|---|---:|---:|---:|---:|
| 고정 LR | 52.52% | 0.4441 | 0.5356 | 0.6948 |
| 고정 MLP | 53.78% | 0.5702 | 0.5679 | 0.6866 |
| 개인별 베타-베르누이 | 68.22% | 0.6571 | 0.7190 | 0.6145 |
| MLP + 지속적 개인 보정 | 67.48% | 0.6546 | **0.7211** | **0.6144** |

- 고정 MLP 대비 적응형 MLP의 **AUC +0.1532**(동일 1,350건).
- 참가자 단위 부트스트랩(2,500회)에서 AUC 차이의 탐색적 95% 구간: **[+0.0775, +0.2224]**.
- 처음 10건으로 보정 후 **고정**한 모델의 AUC는 **0.7119**, 계속 갱신하면 **0.7211**.
- 보정용 시행을 12회 재선정한 같은 Test 대상의 AUC는 **0.7150~0.7328**. 독립적인 12회 재현 검증은 아니다.

### 5.3 결과 해석과 개선의 범위
- **초기 개인화**에서 개선 폭의 대부분이 나타났고, 지속적 갱신의 추가 이득은 비교적 작았다.
- 따라서 이번 분석에서 강하게 뒷받침되는 것은 ‘과거 판단을 통해 **개인별 행동 성향을 추정하는 것**의 정보 가치’다.
- 정확도·AUC가 향상해도 조언 의존의 인과적 이유가 밝혀졌다는 뜻은 아니다.

### 보고서에 넣을 그림 (3개)
1. 전처리 흐름: 295명·23,600건 → 잘못된 조언 11,800건 → 참가자 단위 Train/Validation/Test.
2. 원래 1,800건에서 LR·MLP·기준 모델 성능 비교.
3. 공통 1,350건에서 정적 MLP·초기 개인화·지속적 적응형 AUC 비교(분모 명시).

## 6. 결론 및 고찰(프로젝트 성찰)

### 6.1 최종 결론
> 잘못된 조언과 같은 답을 선택하는 행동은 일반적인 신뢰도 설문과 개인 특성만으로는 충분히 구별하기 어려웠다. 동일 참가자의 과거 판단 결과를 반영하자 공통 평가 자료에서 예측 성능이 향상되었다. 이는 잘못된 조언 수용 행동을 이해하고 예측할 때 **일반적인 신뢰도 외에 개인의 실제 행동 이력을 고려해야 한다**는 근거를 제공한다.

### 6.2 원 연구 질문과의 논리적 연결
1. 잘못된 조언과 같은 답을 선택한 사례가 실제로 관찰된다.
2. 기존 정적 입력으로는 그 행동을 구별하기 어렵다.
3. 개인별 과거 판단을 넣으면 구별 능력이 개선된다.
4. 그러므로 **개인마다 반복적으로 관찰되는 판단 성향**은 설명 후보이자 유용한 예측 정보다.
5. 단, 개인화의 성능 향상은 ‘왜 그 조언을 따랐는가’라는 **심리적 원인 규명**과 다르다. ‘말로 응답한 신뢰’와 ‘실제 수용 행동’이 서로 일치하지 않는다고 직접 입증한 것도 아니다.

### 6.3 연구 한계
- 목표 변수는 ‘틀린 조언과 같은 답을 선택함’이지 ‘조언으로 인해 오답을 선택함’이라는 인과 효과가 아니다.
- B형 조언 정오 배치 중 일부는 원본 집계값에 기반해 복원했다.
- 제시 자극의 실제 개별 시행 순서를 확인할 수 없어 적응형 갱신은 **가상 순서에 대한 사후 시뮬레이션**이다.
- 과거 실험에서 Test를 반복 조회했으므로 **새로운 독립 Test 검증**으로 주장할 수 없다.
- 개인화에는 이전 시행의 정답·응답 결과 확인이 필요하므로 현장 적용은 별도 설계가 필요하다.

### 6.4 프로젝트 성찰
- 자료형·결측값·A/B 조건을 재확인해 잘못 제외했던 데이터를 복구했다.
- 시행 단위 분할 대신 참가자 단위 분할로 데이터 누수를 줄였다.
- 과대적합을 줄이는 것만으로는 **입력 정보의 부재**를 해결할 수 없었다.
- 예측 성능과 인과적 설명을 분리해 해석해야 한다는 점을 확인했다.
- 적응형 실험까지를 **최종 연구 범위**로 마무리하며, 향후 독립 참가자·실제 시행 로그에 대한 검증은 한계와 후속 가능성으로만 언급한다.
